# 릴스·쇼츠 대본 쓰기 (ig-reel)

세로 영상(릴스·쇼츠·틱톡 공용) 대본을 **이야기**로 쓴다. 카드뉴스를 읽어 주는 영상은 안 된다. 조회 50만 넘은 한국어 AI·업무 쇼츠 82편을 측정해 뽑은 기준(`references/hooks.md`)과, 매일 릴스 2~3편을 올리는 계정이 15편을 비교해 정한 이야기 규칙이다.

## 먼저 읽을 것
- `~/.claude/sns/voice.md`(있으면) — 계정·독자·말투.
- `references/hooks.md` — 첫 문장 유형별 조회 중앙값, 길이, 화면 측정치.

## 절차
1. **첫 문장 3안.** 유형을 다르게 쓴다. 가장 센 둘은 문제 상황 공감("회사에서 ○○할 때 어려우셨죠", 터진 60편의 42%)과 숨은 기능·모르면 손해("이거 모르면 매달 손해 봅니다", 조회 중앙 321만). 15~25자, 1.5초 안에 숫자나 서비스 이름, 배경 설명 없이 궁금증 하나. 결론은 숨긴다. 3안을 `scripts/hook_score.mjs` 에 한 줄씩 넣어 점수를 보고 고른다.
2. **이야기 사슬.** 장면 한 줄 = 한 사실. 장면 사이는 "그런데 / 그래서"로만 잇는다("그리고" 나열이면 다시). 사건 → 더 큰 문제 → 결국 보는 사람의 일로 판을 키운다.
3. **중간(50% 지점)에 재훅 한 줄.** "근데 진짜 무서운 건 이 다음이에요."
4. **가장 센 사실은 끝에서 두 번째 장면.** 앞에서 써 버리지 않는다.
5. **끝에서 세 번째쯤 저장할 물건 한 줄.** 복사할 문장·설정 경로를 큰 자막으로 2초 이상 고정("이 화면, 저장해 두면 바로 씁니다"). 이게 있는 편은 저장이 3배였다(14.6 vs 4.8).
6. **끝은 질문 금지. 반전 한 줄**로 첫 장면을 다시 보게 만든다(소름·웃음·"아" 하나). 댓글 유도는 자막·캡션에서.
7. **길이 30~60초**(60초 넘으면 조회 절반). 말은 초당 7.5자 안팎, 0.5초 안에 시작. 낯선 말은 하나까지.
8. **편마다 우리 해석 한 문장**("이건 과장이다", "이건 진짜 써먹을 만하다")을 넣는다. 양쪽 나열로 끝내지 않는다.
9. 대본을 파일(한 줄 = 한 장면)로 저장하고 `node scripts/hook_score.mjs 대본.txt --sec 40` 으로 검사한다. 85점 아래면 표시된 항목을 고친다.

## 출력 형식
```
첫 문장 3안
1. (유형·점수) …
2. …
3. …

대본 (고른 안 기준, 장면마다 한 줄)
1 [훅] …
2 [사건] …
3 [그런데] …
4 [재훅] …
5 [그래서] …
6 [할 일 · 자막 고정] "…"
7 [가장 센 사실] …
8 [반전] …

화면 메모: 위쪽 큰 제목 두 줄(15자 안팎, 끝까지 유지), 자막은 굵은 고딕, 핵심 단어만 색
제목(유튜브용 15~20자, 질문형): …
```

## 하지 않는 것
- 첫 문장에 결말. "그리고"로 이어지는 나열. 질문으로 끝내기.
- 전문용어 그대로(모델·에이전트·프롬프트는 풀어 쓴다). 충격·경악·꼭 보세요.
- 남의 영상·사진을 그대로 쓰라는 지시. 실존 인물 합성. 한자.
- 숫자는 출처에 있는 것만. 확인 안 된 건 "아직 아무도 모른다"로 한 번에.
