# 인스타 캡션 쓰기 (ig-caption)

릴스·캐러셀의 캡션(설명글)을 쓴다. 인스타에서 캡션이 하는 일은 넷이다: **검색**(캡션 속 단어가 해시태그보다 중요) · **'더 보기' 전 첫 줄** · 읽는 시간 · **DM 공유 유도**. 매일 릴스를 올리는 계정이 조사·시험해 정한 공식이다.

## 먼저 읽을 것
- `~/.claude/sns/voice.md`(있으면) — 고정 해시태그·서명·댓글 키워드 문장.
- `references/hashtags.md` — 3단 구조와 주제 태그 은행.

## 절차
1. **검색어 3~5개**를 먼저 정한다. 사람들이 실제로 치는 말: 한글 서비스 이름(챗GPT·클로드·제미나이, 영문보다 한국 검색이 많다) + 걱정·궁금증 단어("챗GPT 개인정보", "AI 회의록"). 헷갈리면 네이버 데이터랩으로 비교.
2. **1줄 = 훅.** 서비스 한글 이름을 앞세우고 결과는 숨긴다. 35자 안(피드에서 둘째 줄로 넘어가면 '더 보기'에 가린다). 소식 선언형("○○ 출시") 말고 궁금증.
3. **2줄 = 댓글 키워드 안내.** "댓글에 '○○' 남기면 ○○ 링크 보내 드려요!" 세트 안에서 키워드는 하나. 캡션 링크는 눌리지 않으니 링크 대신 이 줄.
4. **본문**: 무슨 일 2~3줄(숫자) → "근데" 반전 → 할 일과 몇 장에 있는지 → **"○○한 친구한테 보내 주세요"**(대상을 집어서: "매일 보고서 쓰는 친구") → 한 줄 평(의견 하나) → 서명. 영문 서비스 이름은 본문에 한 번 괄호로 병기(검색용).
5. **해시태그 3~5개, 맨 끝.** 고정 1(#채널이름) + 분류 1(#AI뉴스 / #AI활용) + 주제 1~3(한글 회사명·구체 기능어). #AI 같은 넓은 태그 단독·스팸 태그·영어 남발 금지.
6. **쓰지 않는 것**: "출처:" 줄(출처는 화면 아래 작게), 링크, 수익·부업 표현, 이모지 줄마다, 한자.
7. 파일로 저장하고 `node scripts/caption_check.mjs 캡션.txt --brand 채널이름` 으로 미리보기(더 보기 전 125자)·검색어·해시태그를 확인한다. 85점 아래면 고친다.

## 출력 형식
```
(1줄 훅, 35자 안)
댓글에 '○○' 남기면 ○○ 링크 보내 드려요!

(무슨 일 2~3줄)

근데 (반전 한 줄)

(할 일 · 몇 장에)
(○○한 친구한테 보내 주세요)

(이름) 한 줄: …

#채널 #분류 #주제 #주제
```
검사 결과의 '피드에 보이는 부분' 두 줄을 캡션 아래에 같이 보여 준다.

## 플랫폼이 다르면
- 유튜브 쇼츠 설명: 6~8줄, 해시태그 3개(앞 3개가 제목 위에 뜬다), 링크 넣지 않는다(눌리지 않음) → `yt-short` 스킬.
- 쓰레드: 글이 곧 콘텐츠. 캡션 공식을 쓰지 않는다 → `th-post` 스킬.
