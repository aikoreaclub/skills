# 하루·한 주 시간표와 비율 — 세 채널 운영 기준 (2026-10~11)

## 하루 (쓰레드 중심 계정)
| 시각 | 자리 | 형식 |
|---|---|---|
| 08:00 | 출근길 | 정보형(새 기능·숫자 하나 + "그래서 이렇게 써라") |
| 10:00 | 오전 | 질문형 또는 마감 임박 지원사업 |
| 12:00 | 점심 | 세트 1(릴스 + 쓰레드 단독 글) — 가장 뜨거운 소식 |
| 14:00 | 점심 뒤 | 정보형 또는 해외 화제 + 우리 생각 |
| 16:00 | 오후 | 의견·논쟁형(입장 먼저, 끝은 "여러분은?") |
| 18:30 | 퇴근길 | 세트 2(릴스 + 쓰레드) |
| 20:00 | 저녁 | 21:00 편 예고(결론 숨김) |
| 21:00 | 밤 | 세트 3(써먹기: 쓰레드 사진 글 + 스토리) |
| 23:00 | 자기 전 | 짧은 써먹기 팁(복사해 쓰는 한 줄) |
- 00:00~07:59 새벽은 올리지 않는다. 07:30이 가장 낮았다.
- 하루 글 수를 9개로 늘렸을 때 새 글 조회가 크게 꺾였다(10/5). 6개 안팎이 기준.

## 비율
- **써먹는 법 70% / 소식 30%.** 소식도 "그래서 이렇게 써라"로 끝낸다(경고로 끝내지 않는다).
- 쓰레드 하루 한 편 이상은 **'내 것 확인형'**(대상 + 지금 내 것에 생긴 일 → 확인법 → 할 일 → 한 단어 질문).
- 하루 6개 중 정보형 최소 2, 질문·의견형 최소 1, 해외 화제 활용 최소 2.
- 같은 날 같은 주제 반복 금지. 세트 영상을 쓰레드에 영상으로 올리지 않는다(같은 소재의 단독 글로).

## 속도
- 해외 발표·화제 후 **12시간 안에 게시**. 큰 소식이 잡히면 그날 순서를 바꿔 먼저. 오래된 소식은 뒤 시간대로.
- 새 모델·새 기능 발표 당일은 "써 봤다, 이렇게 쓰세요"를 가장 먼저. 형식은 쓰레드 사진 글. 쇼츠는 그 기능으로 뭔가 만든 사람의 결과물이 있을 때만(사람·결과물 없는 기능 소개 쇼츠 도달 191·206).

## 한 주
- 월: 지난주 복기(sns-audit) → 이번 주 소재 갈래 비율 정하기, "틀만 같고 내용만 바꾼 것처럼 보이는지" 최근 10편 나란히 점검
- 화~금: 시간표대로. 소재는 수요(검색량·댓글 질문)에서, 우리 편 성과는 형식 판정에만
- 토·일: 세트 수를 줄이고 써먹기·성공담 위주
- 매주 월요일 "○월 ○주차 AI 소식" 캐러셀 1편(한 장 한 소식 + "그래서 이렇게 써먹는다")

## 모든 콘텐츠의 끝
- 끝 문장은 하나로 통일: "댓글에 '○○' 남기면 ○○ 정보가 담긴 링크 보내 드려요!" 세트 안에서 키워드도 하나.
- 쓰레드는 DM이 안 되니 "○○ 링크는 댓글에 달아 둠". 유튜브는 "자료실은 채널 프로필 링크에서".
