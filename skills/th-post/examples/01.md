# 실행 예시 (2026-11-09, 검사기 재보정 뒤)

claude -p 에 SKILL.md 와 references(first-lines.md, validation.md)를 주고 아래 요청을 처리하게 했다. 검사 스크립트(v2)는 claude 가 직접 실행했다.

## 요청

```
소재(1차 출처: 구글 워크스페이스 공식 블로그 2026-11-05): 구글 설문지(Google Forms)에 제미나이 분석이 들어간다. 응답을 읽고 경향과 다음 할 일까지 정리해 준다. 회사용(Workspace) 계정부터 차례로 열리고, 개인 계정은 일정 미정.
계정: 밤샘AI(쓰레드, 직장인 독자, "~음/~함" 체 허용, 줄 끝 마침표 없음). 쓰레드 글 하나 써 줘. 첫 줄 3안을 먼저 보여 주고 고른 안으로 완성해. 검사 스크립트 결과도 붙여.
```

## 결과 (고치지 않고 그대로)

`~/.claude/sns/voice.md` 파일이 없어서, 요청에 적어 주신 계정 정보(밤샘AI, 직장인 독자, ~음/~함 체, 줄 끝 마침표 없음)를 그대로 따랐습니다.

## 첫 줄 3안

| 안 | 꼴 | 첫 줄 | 글자 수(띄어쓰기 뺌) |
|---|---|---|---|
| **A** | 내 것 확인 | 회사 계정 구글 설문지, 응답 보는 법이 바뀌는 중임 | 21자 |
| B | 아는 이름 + 작은 쪽(사소한 습관) | 구글 설문지 응답, 이제 하나하나 안 읽어도 됨 | 18자 |
| C | 바로잡기 | 설문 결과 아직도 엑셀로 옮겨서 보면 손해임 | 18자 |

**A안으로 썼습니다.** 독자의 회사 계정에서 지금 바뀌고 있는 일이라서 절차 1번 '내 것' 각도에 그대로 들어맞습니다. 우리 93편에서 이 꼴 4편은 다른 글보다 조회가 약 7.1배(배수 중앙)였습니다. B안과 C안은 그 각도가 없을 때 쓰는 꼴입니다.

## 완성본

```
[첫 줄 꼴: 내 것 확인 · 검사 100점]

회사 계정 구글 설문지, 응답 보는 법이 바뀌는 중임

설문지 안에 제미나이 분석이 들어옴
응답을 다 읽고 어떤 경향인지 정리해 줌
다음에 뭘 하면 좋을지까지 적어 줌

근데 개인 계정은 아직 일정도 안 나옴
회사 계정부터 차례로 열리는 중이라 안 보여도 이상한 거 아님

솔직히 이건 설문 만드는 사람보다 결과 보고서 써야 하는 사람한테 더 큼

회사 계정으로 지난 설문 하나 열어 보면 들어왔는지 바로 알 수 있음

댓글용 링크: 구글 워크스페이스 공식 블로그 2026-11-05 글 주소
```

- 사실은 네 개입니다. 제미나이 분석이 들어온다, 경향과 다음 할 일을 정리해 준다, 회사 계정부터 차례로 열린다, 개인 계정은 일정이 없다. 모두 1차 출처에 있는 내용이고 숫자는 넣지 않았습니다.
- '워크스페이스'는 낯선 말이라 '회사 계정'으로 풀었습니다.
- 끝은 조회를 노려서 질문 대신 할 일 한 줄로 맺었습니다. 답글을 늘리고 싶으면 "설문 결과 정리, 지금 몇 시간씩 걸림?" 같은 질문으로 바꿀 수 있습니다. 다만 우리 93편에서 질문으로 끝난 글은 조회가 0.76배, 아닌 글은 1.76배였습니다.
- 마지막 줄은 출처를 다시 확인해 주세요. 출처에는 분석 기능이 설문지 화면 어디에 나오는지가 없습니다. 차례로 열리는 중이니 "열어 보면 바로 알 수 있음"이 사실과 다를 수 있습니다. 그러면 "회사 계정부터 순서대로 열리니 며칠 뒤에 다시 보면 됨" 정도로 바꾸는 편이 안전합니다.
- 댓글에 달 링크 주소는 제가 직접 확인하지 않았습니다. 올리기 전에 블로그 원문 주소를 넣어 주세요.

## 검사 스크립트 출력 전문

현재 폴더의 `글.txt`로 저장해서 `th_check.mjs`를 실행한 결과입니다.

```
쓰레드 글 검사  100점 — 올려도 됨

· 첫 줄 꼴 내 것 확인형(대상 + 지금 내 것에 생긴 일). 지금까지 가장 센 꼴
    근거: 우리 93편: 해당 4편 배수 중앙 7.1 vs 나머지 0.97
· 첫 줄 길이 21자
    근거: 우리 93편: 30자 이하 1.32배
· 첫 줄 말끝 ~음·~임·~대
    근거: 우리 93편: 1.33배 vs 0.78배
· 반전 뒤집는 줄 있음
    근거: 우리 93편: 1.25배 vs 0.82배
· 단정 한 줄 입장이 있는 줄 있음
    근거: 우리 93편: 1.4배 vs 0.95배 · 외부 49편: 10/16
· 끝 질문 없이 끝남
    근거: 우리 93편: 1.76배
· 길이 162자(띄어쓰기 뺌)
    근거: 우리 93편: 220자 위아래 차이 없음

점수는 우리 계정 93편과 외부 바이럴 49편에 맞춘 값이에요. 표본이 작아 보장이 아니에요.
{"score":100,"grade":"올려도 됨","chars":162,"firstLen":21,"lines":8,"firstLine":"회사 계정 구글 설문지, 응답 보는 법이 바뀌는 중임","firstKinds":["내 것 확인"],"issues":[]}
```

100점은 지금까지 우리 글에서 조회와 같이 움직였던 항목을 모두 갖췄다는 뜻이고, 조회가 많이 나온다는 보장은 아닙니다. 85점 이상 받은 글은 7편뿐이라 표본도 작습니다. 그리고 이번에 '내 것 확인'으로 잡힌 건 첫 줄의 '계정'과 '바뀌는'이라는 낱말 때문입니다. 낱말로만 판정하는 검사라 점수를 너무 믿지는 마세요.
