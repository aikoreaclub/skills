# 쓰레드 글 쓰기 (th-post)

소식이나 자료를 받아 한국어 쓰레드 글로 **따로** 쓴다(영상 대본·카드뉴스를 옮기지 않는다). 규칙은 두 자료를 합쳐 정했고, 어느 쪽에서 확인됐는지 구분해 적는다. 표는 `references/validation.md`.

- **[우리 120편]** 우리 세 계정(밤샘AI·jejeAI·AIKC) 쓰레드 글 120편. 조회는 같은 계정 앞뒤 7일 글의 중앙 대비 배수.
- **[외부 260편]** 한국어 AI·직장·마케팅 쓰레드 계정 20곳의 글 260편. 조회는 그 계정 글의 중앙 대비 배수.

먼저 알아 둘 것: 글의 꼴이 조회를 설명하는 몫은 크지 않다. 검사기 점수와 조회 배수의 순위상관은 우리 글 0.11, 외부 글 0.15다. 85점 이상 글은 우리 1.37배·외부 3.07배, 65점 미만은 0.75배·0.87배. 손해를 피하고 확률을 조금 올리는 도구다.

## 먼저 읽을 것
`~/.claude/sns/voice.md` 가 있으면 읽는다(계정·독자·말투·금지어). 없으면 셋만 묻는다: 계정 이름, 누구에게, 반말인지 존댓말인지.

## 양쪽 자료에서 모두 확인된 규칙 (항상 지킨다)
1. **단정하는 의견 한 줄.** "솔직히 이건 디자이너보다 회사원한테 더 큼". [우리 120편] 있는 글 1.35배 vs 1.0배. [외부 260편] 2.87배 vs 0.99배. 양쪽 나열·얼버무림은 쓰지 않는다.
2. **중간에 한 번 뒤집는다**("근데", "반전은", "사실은"). [우리 120편] 1.25배 vs 0.83배. [외부 260편] 1.12배 vs 1.0배.
3. **본문은 짧게, 나머지는 답글로 넘긴다.** 목록·방법·링크는 "답글에 달아 둠", "👇"으로 예고하고 본문엔 넣지 않는다. [우리 120편] 1.25배 vs 1.0배. [외부 260편] 3.07배 vs 0.94배. 반대로 본문에 번호 목록을 길게 쓴 글은 외부에서 0.5배, 본문 링크는 0.68배였다.
4. **'내 것' 각도가 있으면 그걸 첫 줄로.** 읽는 사람의 기기·계정·일에 지금 생긴 일(대상 + 끊긴·막힌·바뀐). 양쪽 모두 높았지만 3편씩뿐이라 참고로 둔다(우리 5.5배, 외부 1.7배). 예: "윈도우 11인데 10월 13일부터 보안 업데이트가 끊긴 컴퓨터가 있음"(17,682회).

## 한쪽 자료에서만 확인된 규칙 (작게 반영)
- **첫 줄 30자 안.** [우리 120편] 1.25배 vs 0.87배. 외부는 80%가 이미 30자 이하라 차이가 안 보였다.
- **길이 150~280자.** [우리 120편] 1.09배 vs 그 밖 0.67배. 외부는 길이별 차이가 없었다. 쓰레드 한도는 500자.

## 자료가 엇갈리거나 차이가 없던 것 (강요하지 않는다)
- **질문·투표로 끝내기**: 우리 0.78배(61편), 외부 1.75배(9편). 엇갈린다. 답글을 받고 싶은 글에만 쓴다.
- **첫 줄에 아는 이름**: 우리 1.03 vs 1.06, 외부 1.25 vs 1.0. 이름만으로는 약하다. 뜻밖의 작은 쪽(한 사람·며칠·사소한 습관)과 붙을 때 우리 상위 글이 나왔다(21,133 · 10,357회).
- **첫 줄에서 대상 부르기**("직장인이라면"): 우리 0.74배, 외부 1.15배. 부르는 것만으로는 안 된다.
- **본문 해시태그, 첫 줄 숫자, 첫 줄 질문, 줄 끝 마침표, 첫 줄 말끝(~음·~다)**: 차이가 없거나 표본이 5편 안팎이다.

## 절차
1. 소재에서 '내 것' 각도를 찾는다. 없으면 아는 이름 + 작은 쪽, 바로잡기 중에서 고른다.
2. 첫 줄 3안(30자 안)을 쓴다.
3. 본문: 사실 4개까지, 한 줄에 사실 하나. 단정 한 줄, 뒤집는 줄 하나. 낯선 말은 하나까지.
4. 목록·방법·링크가 있으면 본문에서 빼고 "답글에 달아 둠" 한 줄을 넣는다. 답글용 글도 따로 써 준다.
5. 파일로 저장하고 `node scripts/th_check.mjs 글.txt`. 감점마다 근거가 같이 나온다. 양쪽 자료 근거가 붙은 감점부터 고친다.

## 출력 형식
```
[검사 89점]

(글 본문 — 줄바꿈 그대로)

답글 1: (목록·방법·링크)
```

## 하지 않는 것
- 수익·부업 표현, 한자.
- 사실은 1차 출처로만. 숫자는 출처에 있는 것만.
- 검사 점수를 성과 보장처럼 말하지 않는다.
