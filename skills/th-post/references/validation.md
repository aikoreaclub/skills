# 검사기 검증 — 우리 쓰레드 120편 + 외부 계정 297편 (2026-11-09)

`scripts/th_check.mjs` 가 매긴 점수가 실제 조회와 맞는지 두 자료로 확인했다. 도구는 사이트 저장소의 `tools/skills_validate.py`, 외부 수집은 `AI채널_제작/수집/외부검증/th_collect.mjs`.

## 자료
- **우리 120편**: 밤샘AI 93편, jejeAI 12편, AIKC 15편(2026-09-29~11-09). 조회는 같은 계정 앞뒤 7일 글의 중앙 대비 배수.
- **외부**: 한국어 AI·직장·마케팅 쓰레드 계정을 검색어 60개로 찾아, 로그인 없이 공개 프로필과 글 페이지에서 본문과 조회 수를 읽었다. 무게를 정할 때는 20개 계정 260편, 마지막 검증 때는 25개 계정 297편(계정당 6편 이상, 올린 지 2일 지난 글). 조회는 그 계정 글의 중앙 대비 배수. 본문은 분석에만 쓰고 싣지 않는다.

## 지나온 판
- v1: 남의 바이럴 글 49편(조회 4만 넘은 글과 1천 안 된 글 비교)만으로 감점. 우리 글에서 순위상관 0.05, 계정 1위 글을 32점으로 매김. 버림.
- v2: 우리 한 계정 93편으로 다시 맞춤. 그 자료에선 0.28이었지만 외부 글에선 0.10.
- v3(지금): 우리 세 계정 120편과 외부 260편에서 같은 방향인 항목에 무게.

## 스킬을 줬을 때와 안 줬을 때
같은 소재 3개를 같은 모델(claude opus)에게 한 번은 "쓰레드 글 써 줘"만, 한 번은 이 스킬을 주고 쓰게 한 뒤 v3 로 채점했다.

| 소재 | 스킬 없이 | 스킬 |
|---|---|---|
| 구글 설문지 제미나이 분석 | 50점 | 89점 |
| 회사용 클로드 관리 기능 | 65점 | 89점 |
| AI 바우처 2차 공고 | 89점 | 89점 |
| 평균 | 68.0 | 89.0 |

채점 기준이 스킬의 규칙과 같으니 "스킬이 규칙대로 쓰게 만든다"는 확인이지 조회가 오른다는 증거는 아니다. 스킬 쪽 글은 v2 규칙으로 쓴 것이다.
