# 자주 막히는 곳과 답

| 증상 | 답 |
|---|---|
| 휴대폰 문자 인증이 안 와요 | 인터넷 전화(VoIP)·유선 번호는 안 됩니다. 지원 지역의 일반 휴대폰 번호로. 인증은 건너뛸 수 없어요. |
| `claude` 를 치면 command not found / 인식되지 않는 명령 | 설치 폴더가 아직 PATH 에 없어요. 터미널 창을 닫고 새로 연 뒤 다시. 그래도 안 되면 설치 명령을 한 번 더 돌리고, 설치 끝에 나온 안내(PATH 추가 줄)를 따라요. |
| 윈도우에서 `irm` 을 인식할 수 없다 / `&&` 가 올바른 구분 기호가 아니다 | 지금 창이 CMD 예요. 시작 메뉴에서 PowerShell 을 열어 다시 붙여 넣어요. |
| 로그인은 됐는데 403 오류 | 클로드 코드는 Pro·Max·Team·Enterprise 또는 Console(API 결제) 계정이 필요해요. 무료 요금제에는 없어요. |
| 로그인 브라우저 창이 안 열려요 | 클로드 코드 화면에서 `c` 를 누르면 로그인 주소가 복사돼요. 브라우저 주소창에 붙여 넣어요. Invalid code 가 나오면 코드 만료, 처음부터 다시. |
| 윈도우에서 Git for Windows 가 필요하다고 해요 | 클로드 코드는 윈도우에서 Git Bash 나 PowerShell 로 명령을 실행해요. git-scm.com 에서 Git for Windows 를 설치한 뒤 다시. |
| 데스크톱 앱 로그인 후 대화 목록이 비어 있어요 | 다른 계정으로 로그인한 거예요. 설정에서 이메일을 확인하고 웹과 같은 계정으로. |
| 프로젝트에 파일이 안 올라가요 | 파일 하나 30MB 제한, 지원 형식(PDF·DOCX·XLSX·CSV·TXT·JPEG·PNG)인지 확인. 한글(HWP)은 PDF 로 바꿔서. |
| 답이 영어로 나와요 | 한국어로 질문하면 한국어로 답해요. 지침(5단계)에 "한국어 존댓말로"를 넣어 두면 늘 한국어예요. |
