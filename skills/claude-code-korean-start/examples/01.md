# 실행 예시 (2026-11-08)

요청: "윈도우 노트북 쓰는 회사원인데 클로드 코드 처음 깔아 보려고요. 뭐부터 하면 돼요?"

결과(고치지 않음) — 첫 답변:

안녕하세요! 윈도우 노트북이시군요. 한 번에 한 단계씩 같이 가 볼게요. 전체 순서를 먼저 보여 드리고, 오늘은 첫 단계부터 시작하겠습니다.

**전체 순서 (30분 정도)**

1. 클로드 계정 만들기 (무료)
2. 요금제 고르기 → 클로드 코드는 **Pro 이상**이 필요해요
3. 데스크톱 앱 설치
4. 첫 설정(지침) 넣기
5. 첫 결과물 하나: 회의 메모 → 보고서
6. 클로드 코드 설치 (PowerShell)
7. 클로드 코드 첫 명령

---

**1단계. 계정 만들기**

1. 브라우저에서 `claude.ai` 에 들어가세요.
2. **"Google로 계속하기"** 를 누르거나, 회사 이메일을 넣고 받은 링크를 클릭하세요.
3. 처음에는 **휴대폰 문자 인증(6자리)** 을 꼭 해야 해요. 일반 휴대폰 번호만 됩니다. 인터넷 전화나 회사 유선 번호는 안 돼요.
4. 만 18세 이상만 가입할 수 있어요.

✅ **이렇게 보이면 성공:** 화면 왼쪽 아래에 내 이름 첫 글자가 동그라미 안에 보여요.

---

**미리 알려 드릴 것 하나**

클로드 코드는 무료 요금제에서는 안 됩니다. Pro 이상이 필요해요. 금액은 `claude.com/pricing` 에서 한 번 더 확인해 주세요. 바뀌는 경우가 있어서요.

계정이 이미 있으시면 "계정 있어요"라고 말씀해 주시고, 없으시면 1단계를 끝내고 "성공"이라고 알려 주세요. 다음 단계로 넘어갈게요.
