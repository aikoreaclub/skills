# 유튜브 쇼츠 제목·설명 쓰기 (yt-short)

쇼츠 피드에서 제목은 화면 아래 작은 한두 줄로만 보이지만, 채널 쇼츠 목록·검색·관련 영상에서는 **제목이 곧 클릭 이유**이고 유튜브가 영상 주제를 파악하는 1순위 글자다. 화면 속 3초 훅(감정)과 역할을 나눈다: 제목 = 검색어 + 사실 + 궁금증. 조회 50만 넘은 한국 쇼츠 82편의 제목 분석(길이 중앙 21.5자, 숫자 35%, 방법·해결 20%, 숨은·모르면 15%, 물음표 11%)과 "쉬운 말·큰 의미·질문형" 규칙이다.

## 제목 규칙
**제목은 뉴스 요약이 아니다. 보통 사람이 느낄 '큰 의미'를 쉬운 말로 던지는 질문이다.**
1. **쉬운 말만.** 전문 용어·기사 단어 금지(난제·비공개·탐지기·선언문·모델·에이전트 → 빼거나 풀어 쓴다). 초등학생도 읽히게.
2. **큰 의미로 올려 말한다.** 사건 자체보다 "그래서 사람한테 무슨 일?"(내 일자리·내 사진·내 돈·AI가 어디까지). 예) 수학 난제 발표 → "수학자도 대체하려는 AI?"
3. **질문형(~?) 또는 반쯤 놀란 말투**, 15~20자.
4. 검색어는 기본 단어면 충분(AI·챗GPT). 앞에 두면 좋지만 쉬운 말이 우선.
5. 사실을 뒤집지 않는다. 영상 내용과 반대되는 말 금지. 충격·경악·실화·【】·#shorts 금지. 날짜·긴급 머리말은 발표 24시간 안 속보에만.

## 절차
1. 영상(대본·요지)을 읽고 "그래서 보는 사람한테 무슨 일인가"를 한 문장으로 쓴다.
2. 제목 3~5안을 쓴다(질문형·반쯤 놀란 말투·숨은 기능 꼴·방법 꼴을 섞어서).
3. `node scripts/title_check.mjs "안1" "안2" "안3"` 으로 나란히 점수를 본다. 어려운 말·금지어가 걸리면 그 안은 고친다.
4. 설명 6~8줄: 첫 줄은 말 걸기("밤새 이거 봤는데요") → 무슨 일 2~3줄 → 할 일 1줄 → 빈 줄 → 해시태그 3개(앞 3개가 제목 위에 뜬다: 분류 1 + 주제 2). 링크는 넣지 않는다(쇼츠 설명 링크는 눌리지 않는다). 출처는 이름만("출처 · 오픈AI 공지").
5. 가능하면 유튜브 스튜디오 제목 비교 시험에 두 안을 건다. 없으면 비슷한 소재끼리 공식을 바꿔 가며 주간 비교.

## 출력 형식
```
큰 의미 한 문장: …

제목 후보 (검사 점수순)
1. (점수) …
2. …
3. …

설명
(6~8줄)

#분류 #주제 #주제
```

## 예 (실제 적용)
| 전(어렵다) | 지금 |
|---|---|
| 챗GPT 개인정보, 이건 좀 무섭다 | 내가 올린 사진, AI가 퍼뜨렸다? |
| AI 수학 난제 100개? 증명은 비공개 | 수학자도 대체하려는 AI? |
| AI 탐지기에 찍힌 소설, 남 일 아니다 | 사람이 쓴 소설, AI가 썼다고 우긴다? |
