# 유튜브 쇼츠 제목·설명 쓰기 (yt-short)

먼저 알아 둘 것: **쇼츠 제목은 조회에 주는 영향이 작다.** 한국 AI·업무·IT 채널 23곳의 쇼츠 2,314편을 그 채널 조회 중앙 대비 배수로 봤더니, 어떤 제목 특징도 1.2배를 넘지 못했다. 그러니 이 스킬은 "조회를 터뜨리는 제목"을 약속하지 않는다. 손해 보는 제목을 피하고, 검색과 채널 목록에서 무슨 영상인지 바로 알게 하는 것이 목표다. 조회는 첫 문장과 내용이 정한다(`ig-reel` 스킬).

근거 표는 `references/validation.md`.

## 자료에서 확인된 것 [외부 2,314편]
**손해였던 제목**
- 31자 이상: 0.82배(192편). 30자 안으로 쓴다.
- 돈·가격을 앞세운 제목(만원·무료·가격·월급): 0.83배(77편).
- 명령형(~하세요·~마세요): 0.93배(80편).

**조금 유리했던 제목**(크지 않다)
- 따옴표로 누군가의 말·화면 속 문장을 그대로: 1.2배(115편).
- 숫자: 1.12배(563편). vs·비교·차이: 1.12배(55편).
- 이유·진짜·사실·정체: 1.08배(259편). 사람이 보이는 제목(직장인·개발자·사장…): 1.06배(150편).

**차이가 없던 것**(통념과 다름)
- 질문형(물음표): 0.94배(429편). 유리하지 않았다.
- 감탄·과장(ㄷㄷ·미친·대박·충격): 1.03배. 방법·꿀팁: 1.03배. 숨은·모르면: 1.02배. AI 단어: 1.02배. 이모지: 1.0배.
- 길이 12자 이하·13~20자·21~30자: 1.0 · 1.0 · 1.04배. 30자 안이면 길이는 상관없다.

## 절차
1. 영상(대본·요지)을 읽고 무슨 영상인지 한 문장으로 쓴다.
2. 제목 3~5안을 쓴다. 30자 안, 쉬운 말. 영상 속 누군가의 말이나 화면 문장이 있으면 따옴표로 한 안, 숫자가 있으면 숫자로 한 안, 이유·정체로 한 안.
3. `node scripts/title_check.mjs "안1" "안2" "안3"` 으로 나란히 본다. 감점(31자 이상·돈 표현·명령형)이 걸린 안은 고친다.
4. 사실을 뒤집지 않는다. 영상 내용과 반대되는 말 금지. 계정 말투 규칙(예: 충격·실화 안 씀)은 성과와 무관하게 voice.md 를 따른다.
5. 설명 6~8줄: 무슨 일 2~3줄 → 할 일 1줄 → 빈 줄 → 해시태그 3개(앞 3개가 제목 위에 뜬다). 링크는 넣지 않는다(쇼츠 설명 링크는 눌리지 않는다). 출처는 이름만.
6. 가능하면 유튜브 스튜디오 제목 비교 시험에 성격이 다른 두 안을 건다. 내 채널 자료가 이 표보다 정확하다.

## 출력 형식
```
무슨 영상인가: …

제목 후보 (검사 점수순)
1. (점수) …
2. …
3. …

설명
(6~8줄)

#분류 #주제 #주제
```

## 하지 않는 것
- "이 제목이면 조회가 오른다"고 말하지 않는다.
- 어려운 말(난제·탐지기·에이전트·프롬프트)은 쉬운 말로. 한자, #shorts, 【】.
